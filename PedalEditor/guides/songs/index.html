Working map. Every item below is a real tap target — content strategy still to be decided.

Tab header

  • Segmented control — Songs / Setlists (haptic selection)

Songs list

  • + in header → New Song sheet
  • Search (when list non-empty)
  • Empty state — Create Song button
  • Song card — tap opens Song Editor; long-press → Rename / Delete

Song Editor

  • Nav bar — Details (info icon) · Save (when changed) · Dev Export (debug only)
  • Section headers — tap select; context menu → Rename / Delete Section
  • Preset rows — content: order #, name, pedal / PC / channel; context menu → Rename / Delete; swipe Delete; drag to reorder
  • Action bar — Add Preset → picker sheet; Section → Add Section sheet

Sheets inside Song Editor

  • Song Details — Name / Key / Tempo / Notes (Done, does not auto-save)
  • Preset Picker — per-pedal list of saved presets
  • Add Section — quick-pick chips (Verse, Chorus, Bridge…), custom name, Copy Presets From…
  • Rename Section / Preset alerts

Setlists list

  • + in header → New Setlist sheet
  • Search (when list non-empty)
  • Empty state — Create Setlist button
  • Setlist card — tap opens Setlist Editor; long-press → Rename / Delete

Setlist Editor

  • Nav bar — searchable (“Search songs”) · Edit (iOS) · + Add Song
  • Song row — content: order #, name, preset count, key, tempo; context menu → Remove from Setlist; swipe Remove; drag to reorder
  • Live-tab reminder banner (read-only)
  • Add Song sheet — per-song row Add (auto-close when all added)

Not yet decided

  • Whether Songs and Setlists deserve two separate guide pages or stay as one
  • Whether the empty-state copy (“Create songs in the Songs tab first”) is worth calling out as a distinct flow
