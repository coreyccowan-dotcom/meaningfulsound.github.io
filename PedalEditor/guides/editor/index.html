Working map. Every item below is a real tap target — content strategy still to be decided.

The pane

  • Category cards (row 1) — pick effect family
  • Algorithm cards (row 2) — pick machine
  • Parameter controls — knobs, toggles, selectors, buttons, dip banks
  • Physical Switch panel (when the profile has one)
  • Global Parameters / App Globals sections
  • Frozen overlay (unowned profile) — Start Trial, Connect this Profile, Get Lifetime

iPhone gestures on the pane

  • Tap pedal name — toggle bypass
  • Swipe pedal name L/R — previous / next pedal in rig

Sidebar (iPad/Mac) · Amp popover (iPhone)

MIDI

  • Connection banner → MIDI Destination Picker

Pedal

  • Pedal card → pedal picker (grouped by manufacturer, searchable)
  • Ch pill — MIDI channel 1–16
  • MIDI Ref pill → per-profile MIDI reference (when present)

Rig / Project / Collection

  • Rig card → Rig manager sheet
  • Project card → Project manager sheet
  • Collection pill → bank picker (with Create… and Manage…)

Action bar (iPad/Mac, when a preset is selected)

  • Save — writes to app (may raise Overwrite alert)
  • Save on Pedal — either confirm alert or manual-save instructions
  • More (…) popover — Read from Pedal · Discard Capture · History · Undo · Redo · Edit Profile

Admin footer

  • Profiles · Monitor · Connect to Mac (iOS) · Settings

iPhone toolbar (top nav)

  • Amp icon (leading) → controls popover (see sidebar above)
  • Preset name (centre) → preset picker sheet
  • Save Options popover (trailing) — Save to App · Save to Hardware · Read from Pedal · History · Undo · Redo · Edit Profile

Preset list

  • New Preset (+) → Preset Template Picker
  • More (…) — Edit · Organize (Group Manager) · Filter
  • Search field
  • Preset row — tap to load
  • Swipes — left favorite, right mark empty
  • Row context menu — Favorite · Rename · Duplicate · New from Template · Start Group Selection · Delete
  • Group header context menu — Edit Group · Color · Delete Group

Sheets reached from Editor

  • MIDI Destination Picker — connect / rescan / pair BLE / disconnect
  • Rig — create, edit, per-pedal channels; nested Add Pedal picker
  • Project Manager — create, rename, activate
  • Profiles — activate, MIDI settings, Reset, Create Your Own
  • MIDI Reference — searchable CC catalogue
  • MIDI Monitor — Pause · Export · Clear
  • Hardware Capture — capture all presets from the pedal
  • Settings — Lifetime, Restore, Backup & Restore, links, onboarding, haptics, DEV
  • Bank picker — Create Collection, Manage Collections
  • History — per-change revert, Clear
  • Preset Template Picker — new preset from seed
  • Preset Group Manager — Create Group, Edit Group, Delete, reorder

Not yet decided

  • Edit Profile chain (More → Edit Profile) is currently live but marked retired in project notes — document, hide, or remove?
  • Where Save to App vs. Save on Pedal deserves its own short explainer (currently spans two entry points)
