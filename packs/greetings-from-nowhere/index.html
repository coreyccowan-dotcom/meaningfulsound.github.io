The pack

Greetings From Nowhere is the first preset pack from Meaningful Sound. Forty-eight presets, nineteen songs, seven setlists, and four collections built for four specific pedals: Strymon BigSky, Strymon Timeline, Walrus Audio ACS1 mk1, and Walrus Audio M1 mk1.

Pedals required

  • Strymon BigSky reverb
  • Strymon Timeline delay
  • Walrus Audio ACS1 mk1 amp & cab

If you’re running a subset of these, the rest of the pack still installs cleanly. Presets for pedals you don’t own are there when you’re ready for them. Nothing is missing — just waiting.

How to install

This pack requires a current TestFlight build of PedalEditor. The public App Store version may not yet include .presetpack support — the TestFlight build is where that handler lives.

  1. Tap Get the Pack below.
  2. The .presetpack file downloads to your device.
  3. Open it from Files — PedalEditor launches automatically.
  4. An install sheet appears. Review what’s coming in, then confirm.
  5. The pack lands in your library with its own IDs. Installing again later won’t clobber anything already there.

That’s it. No account. No sync step. No cloud required.
