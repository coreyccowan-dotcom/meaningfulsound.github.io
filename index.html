About

Meaningful Sound is an independent studio building native software for guitarists, songwriters, and producers. The apps share a common philosophy: solve a real problem for working musicians, ship native code, and never collect data we don't need to run.

Best known for PedalEditor — the premier iPhone Bluetooth and Wi-Fi MIDI controller and editor for guitar pedals and synths, with a library system designed for how musicians actually think.
